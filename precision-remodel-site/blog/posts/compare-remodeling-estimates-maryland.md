Compare remodeling estimates by lining them up line by line, not by the bottom-line total. Check that each bid covers the same scope, materials, allowances, permits, inspections, cleanup, timeline, and payment terms, and that the contractor holds an active MHIC license. A lower number often means something is missing, not that the work is cheaper.

## Why can estimates for the same kitchen be so far apart?

Two contractors can look at the same kitchen and price two different jobs. The gap usually comes from what each one assumed, not from one of them being a better negotiator.

The most common reasons we see:

- **Different scope.** One bid includes new subfloor repair, electrical updates and drywall finishing. The other says only "install cabinets and counters."
- **Different allowances.** One contractor budgets a realistic number for tile, fixtures or appliances. The other uses a low placeholder to make the total look attractive.
- **Different assumptions about permits.** One includes permit and inspection coordination. The other leaves it to you.
- **Different crews and overhead.** Licensed, insured trades working under a project manager cost more than a pickup-truck crew that skips steps.
- **Different levels of detail.** A one-page bid with a single lump sum hides everything above. A detailed bid shows its work.

Pricing depends on scope, so no total means anything until the scope matches. ## How do I compare contractor bids line by line?

Put the bids side by side in a simple grid and mark every line as included, excluded, or not mentioned. The "not mentioned" boxes are where surprises come from.

Here is the grid we suggest:

| Item | Bid A | Bid B | Bid C |
|---|---|---|---|
| Demolition and debris haul-away | | | |
| Cabinets (brand, line, size, install) | | | |
| Countertops (material, edges, cutouts, sink) | | | |
| Plumbing changes | | | |
| Electrical changes (circuits, lighting, GFCI/AFCI) | | | |
| Flooring and subfloor repair | | | |
| Drywall, paint, trim | | | |
| Permits and inspections | | | |
| Allowances (amount and items) | | | |
| Start date, duration, schedule | | | |
| Payment schedule | | | |
| Warranty terms | | | |

If a line is blank on one bid, ask the contractor about it in writing. Do not assume it is covered.

## What scope lines should every estimate spell out?

A good estimate names materials, quantities and tasks, not just categories. If you could not hand the document to a different contractor and get roughly the same job, it is too vague.

Look for these in each bid:

- **Demolition and disposal:** who removes debris, and whether a dumpster is included.
- **Materials by name:** cabinet manufacturer and line, countertop material, tile size and pattern, fixture finish. Vague phrases like "quality tile" are a warning.
- **Trade work:** plumbing, electrical and HVAC changes described separately, and who performs them. Ask whether licensed trades are doing the regulated work.
- **Hidden-condition handling:** what happens if the crew opens a wall and finds something unexpected, and how that gets priced.
- **Finish work:** drywall patching, priming, painting, trim, and touch-up after other trades finish.
- **Protection and cleanup:** floor protection, dust barriers, daily cleanup and final cleaning.
- **Schedule:** a start window and a realistic duration, not just "a few weeks."

If a bid involves moving or removing a wall, ask how the contractor handles it. Structural questions call for a licensed engineer, not a guess. ## What are allowances, and where do they hide risk?

An allowance is a budgeted amount for items not yet selected, such as tile, plumbing fixtures, lighting or appliances. The risk is that a low allowance makes a bid look cheaper, then you pay the difference when you pick real products.

When comparing allowances:

1. **List every allowance** in each bid and its dollar amount.
2. **Shop a few real products** at that number. If the allowance for kitchen tile or a vanity would not buy anything you like, the true cost is higher than the bid shows.
3. **Compare like with like.** If Bid A allows a certain amount for fixtures and Bid B allows far less, that gap is part of the price difference.
4. **Ask what happens if you come in under.** A fair contract credits you back.
5. **Ask whether installation is inside or outside the allowance.** Some contractors budget only the material.

High-end kitchens and bathrooms tend to run over low allowances quickly, because the selections people actually want are rarely the placeholder grade.

## Who pulls permits, and what inspections should the estimate include?

The estimate should state who applies for permits, who schedules inspections, and who is responsible if an inspection fails. Requirements vary by jurisdiction and by scope, so confirm with the local permit office rather than relying on a contractor's say-so alone.

In Baltimore County, permits go through the county's permit and inspection office. Neighboring counties and cities such as Baltimore City, Harford and Howard each run their own process. Ask your local office what your specific project needs, especially if it involves electrical, plumbing, or structural changes.

Red-flag answers to watch for:

- "You don't need a permit for that." Maybe true for cosmetic work, but ask them to put the reasoning in writing, then check with the county.
- "Have the homeowner pull it." Sometimes legitimate, but it can shift responsibility onto you. Ask why.
- Permits listed as an extra with no amount, which leaves an open-ended cost.

Unpermitted work can surface later during a sale or an insurance claim. Pulling permits is a cost of doing the job properly, and it belongs in the estimate.

## What would an inspector flag that cheap bids leave out?

Cheap bids tend to leave out the unglamorous work that inspectors look at: electrical, plumbing and finish-stage details. Precision Remodel's background includes inspection work, so we read bids the way an inspector reads a finished room.

When reviewing a bid, ask whether it covers items like these, and let your local inspector confirm what applies to your project:

- **Electrical:** whether new or relocated circuits, outlet placement, and required protective devices are included, rather than just "swap fixtures." Ask who handles the electrical work and whether it is permitted.
- **Plumbing:** shutoffs, proper supply and drain connections, venting where lines are moved, and accessible connections.
- **Ventilation:** a plan for range hood or bathroom exhaust, including where it vents.
- **Moisture control in bathrooms:** waterproofing behind and under tile, not only the tile itself. Ask the contractor to describe their shower waterproofing method.
- **Framing and structure:** anything that touches a wall, beam or floor system should involve an engineer's input where needed, not the contractor's opinion alone.
- **Rough-in access:** work scheduled so inspections can happen before walls are closed up.

A bid that does not mention any of these is not necessarily dishonest, but you should ask why. Missing line items are often how a low price is built. ## What are the red flags in a contractor estimate?

The biggest red flags are vagueness, pressure and missing paperwork. Any one of these is worth a direct question before you sign.

- **No MHIC license number.** Maryland requires licensing for home improvement contractors. You can verify a license with the Maryland Home Improvement Commission. Precision Remodel is licensed under MHIC #151439.
- **A single lump sum** with no breakdown of labor, materials or allowances.
- **Pressure to sign today** or a discount that expires in 48 hours.
- **A very large deposit request,** or payment that is not tied to progress. See the FAQ below.
- **No written contract** or a contract that does not match the estimate.
- **No mention of insurance,** or reluctance to provide proof.
- **A price far below the others** with no explanation. Ask what they left out.
- **No schedule,** or a start date that keeps slipping before you have even signed.
- **Vague warranty language,** such as "we stand behind our work" with no stated terms.

The lowest bid is not always wrong and the highest is not always best. Choose the contractor who can explain every line and whose scope you can verify.

## FAQ

### How much deposit can a Maryland contractor ask for?

Maryland law limits the deposit a contractor may collect on a home improvement contract. The exact cap is set by the Maryland Home Improvement Commission and the state's home improvement law, so confirm the current limit with the MHIC before you pay. Be cautious of anyone asking for much more up front.

### What is a change order, and how should it be handled?

A change order is a written agreement to change the scope, price or schedule after the contract is signed. It should describe the change, the cost, and any effect on timing, and both you and the contractor should sign it before the work happens. Avoid verbal agreements.

### How should payments be scheduled on a remodel?

Payments should follow completed stages of work, not the calendar. A typical structure ties payments to milestones such as demolition, rough-in, inspection passes and substantial completion, with a final payment held until the punch list is done. Ask each contractor to put their schedule in the contract, and check it against MHIC rules.

### How many remodeling estimates should I get?

Two to three detailed estimates are usually enough to see where the scope and pricing differ. More than that tends to add confusion unless the project is large or unusual. Give every contractor the same written description so the bids are comparable.

### Should I just pick the lowest bid?

Not without checking what it includes. Compare scope, allowances, permits, license, insurance and payment terms first. If the lowest bid matches the others line by line, it may be a good value. If not, the difference is probably missing work.
